In this new work, I built an evaluation metric and a multi-agent framework for video-game generation.

First, I made a new evaluation metric called AVR-eval for multimedia content (e.g., video games and animations) through  Audio-Visual Recordings (AVR). Contrary to [FVD](https://arxiv.org/abs/1812.01717), it does not require a dataset of examples, and contrary to [WebDev Arena](https://web.lmarena.ai/), it does not require human evaluation. AVR-eval uses an omni-modal (processing text, audio, and video) model in order to compare the AVR of two contents in order to determine which is the best.

Then, from this metric, I tested generation for web (JavaScript + HTML) animations and games.

While coding models can generate content in a single prompt, performance can be enhanced with multiple steps of improvement. Meanwhile, agent frameworks do not handle audio, video, 3D models, and custom assets, which are important for web games. To solve this issue, I built AVR-Agent, a multi-agent system for generating JavaScript content from a bank of multimedia assets (audio, images, and 3D models).  In AVR-agent, the coding agent selects the relevant assets and generates an initial code. Then, it improves the code through feedback from an omni-modal agent that processes the AVR of the content.

I show below examples of generated games. Read the [paper](Soon) for more details. The code for AVR-Eval and AVR-Agent is available [here](https://github.com/SamsungSAILMontreal/AVR-Eval-Agent).
